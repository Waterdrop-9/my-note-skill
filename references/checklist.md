# Visual Quality Checklist

排版完成后检查，配合 [Content Quality Checklist](content-checklist.md)。视觉通过不能抵消内容 P0 失败。

## 最高优先级：让布局容纳理解

**不得为了让页面更短、更整齐，而删除理解所必需的内容。** 内容太长时依次考虑：

1. 增加页面，保留完整知识链。
2. 按逻辑拆分 section，保留桥接与回收。
3. 拆分多个 HTML，提供入口和前后篇链接。
4. 将确实低优先级的扩展移至 OPTIONAL，主线不可依赖被移走的解释。

关键推导、承上启下、原因、初学者断点、必要示例与边界条件不能因版面被删除。页高统一是视觉偏好，不是内容容量上限；必要时让容器随正文增高。

## P0 · 所有风格必须通过

- [ ] 已完成内容审查，排版没有丢失草稿中的关键解释。
- [ ] `<title>`、正文标题、目录、来源已替换；没有占位符或无关模板内容（B 包含底部 `texts`）。
- [ ] HTML 可在浏览器正常打开，中文使用 `lang="zh-CN"` 和 UTF-8。
- [ ] 公式、代码、表格、链接没有因转义／语法错误改变含义。
- [ ] 内容没有裁切、遮挡或不可访问的部分；避免固定高度配 `overflow: hidden` 吞正文。
- [ ] 章节 ID 唯一，目录／跨篇／来源链接与文件路径正确。
- [ ] 不使用 emoji 作图标／装饰；需要图标时 A 用 Lucide，B 用 Remix Icon，C 可不用或用内联 SVG。
- [ ] 正文在桌面和窄屏可读；宽表、长代码和公式局部滚动，页面无横向溢出。
- [ ] 验证记录准确：实际浏览器检查、静态检查、未验证项分别如实说明。

## Style A · 保留手写笔记本

- [ ] Kalam / Patrick Hand / Zeyada 加载或字体回退可读。
- [ ] Lucide CSS 正确引入，所需图标能显示。
- [ ] 螺旋装订、横线和装订线正常；便签不挡正文。
- [ ] write-in 动画可用，延迟合理，内容不会长期隐藏。
- [ ] 装饰克制：Lucide 涂鸦建议不超过 3 个、opacity ≤ 0.15；咖啡渍建议不超过 2 个。

## Style B · 保留皮革本与翻页

- [ ] Kalam / Ma Shan Zheng / Zeyada 与 Remix Icon 加载或合理回退。
- [ ] 皮革封面与金属环正常，键盘←→、空格、封面点击及翻页按钮可用。
- [ ] 初始封面 active；每页 `data-page` 与显示页码正确，`totalPages` 从实际 `.page` 数量取得。
- [ ] 每页正文都能完整访问；当前页参与正常文档流，皮革容器随内容增高。
- [ ] 移动端 `.pages-container` 和 `.page` 的最小高度对应，长页不溢出封面边界。
- [ ] 内容过长时按逻辑拆页并增加导航，不靠压缩关键解释维持相同高度。

## Style C · Deep Study

- [ ] 暖白底、serif 标题、sans-serif 中文正文、monospace 代码，字体失效时仍可读。
- [ ] 开头有大图景、阅读优先级与目录；标题层级 h1 → h2 → h3 清晰。
- [ ] 颜色语义稳定：蓝解释、青桥接／流程、橙洞察、红误解／面试、绿解法、紫推导／扩展；同时用文字说明功能。
- [ ] 公式精排成功，无 `.katex-error`、未配对分隔符或资源失败提示；来源与符号解释在附近。
- [ ] 检查无网络／禁用 JS 的降级：正文静态存在、公式 TeX 与文字说明仍可读。降级不等于公式精排通过。
- [ ] 代码保留缩进，长行可滚动，必要的 shape／状态说明可见。
- [ ] transition、insight 等组件由语义选择，普通解释仍用连贯段落。
- [ ] CORE 必要内容没有折叠隐藏；OPTIONAL 明确用途与停止标准。
- [ ] 键盘可访问目录及横滚区域，焦点可见，不以颜色作为唯一提示。
- [ ] 打印预览中公式、表格、代码不被裁切，正文可自然分页。

## P1 · 阅读节奏与细节

- [ ] 流程箭头方向正确；原因、数据流和对比分清，不制造假因果。
- [ ] 对比使用共同维度，条件表有清楚的表头与分组。
- [ ] 段间留白充足，正文宽度适中；移动端字体无需缩小才能塞入。
- [ ] 多文件的主线、扩展和实现参考有明确依赖，不遗漏入口。

## 常见问题

**内容超过原来的封面高度？** 先拆页／拆节；保留关键解释，容器允许随当前页增高。C 长文没有固定页高。

**公式只显示 TeX？** 检查 KaTeX CSS、主脚本、auto-render 版本是否一致及网络是否可达，再检查公式语法。正文可读只是降级；完成精排后再通过公式 QA。

**字体或图标不可达？** 检查网络与字体回退；字体加载失败不能导致中文丢失。严格离线需求需另行打包资源。

**B 换页后正文还是原来的主题？** 除页面 HTML，还要替换底部 `texts`。所有原始案例都只供布局参考。
